# Brew & Bloom — Café Website

Group 1: Café Website.

## Features
- Responsive navigation menu
- Hero, story, menu, quote, visit and reservation sections
- Table-request form with browser-side confirmation
- CSS grid layouts and mobile media query
- Plain HTML, CSS and a small amount of JavaScript

## Preview
Open `index.html` in a browser.

## Important
The reservation form is a front-end demonstration only. It does not send bookings to a real café. Replace the sample café details, menu and contact information before submission.
